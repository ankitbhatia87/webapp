My Philosophy

The PUREST approach to frontend excellence.

Six principles I hold every architecture decision to — each one earned on a real production system, not a whiteboard.

P

Performance

Reworked blocking API patterns at Banxa to cut checkout LCP from 7.0s to 3.0s — the fix that mattered more than a rewrite.

U

User-centric

Built partner customisation at Banxa specifically to reduce dependency on redirected checkout experiences.

R

Responsive architecture

Designed the micro-frontend SPA behind Novo's Debit Card and Funding products for independent, low-risk deploys.

E

Error handling

Led self-custodial wallet validation for MiCA compliance — designed so failures reduce risk, not create it, on live transaction flows.

S

Security & compliance

Treat regulation as a feature: MiCA requirements shipped inside the product, not bolted on before a deadline.

T

Testability

Drove TypeScript adoption and enforced ESLint/pre-commit standards at Banxa and Sberbank to keep code reviewable and safe to change.
